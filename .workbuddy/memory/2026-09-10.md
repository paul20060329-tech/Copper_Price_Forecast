
## 铜价预测项目 · 打包分发（exe + 环境文件）
- 重构：拆出 paths.py（资源路径，兼容 sys._MEIPASS）、logs.py（std 日志）、trainer.py（torch 训练，仅 --retrain 时 importlib 动态加载）。
- 演示快路径只依赖 numpy + 标准库，故 PyInstaller 冻结包不含 torch/pandas/scipy，exe 仅 ~25MB。
- 新增 requirements.txt（pip）、environment.yml（conda）、build.bat / build.sh。
- 用 Anaconda Python 构建（managed python 3.13 缺 tcl/tk，tkinter 会被排除导致弹窗失效）。
- 关键坑：PyInstaller --add-data 的 DEST 必须是目录（如 ），不能是带扩展名的文件路径（如 ），
  否则会被当成目录导致 open() 报 PermissionError。已修正 build 命令与脚本。
- 产物：dist/CopperPriceForecast.exe（双击即用）+ dist/CopperPriceForecast.zip（单文件分发）。
- print 摘要含 R²/→ 在中文 Windows GBK 控制台会 UnicodeEncodeError；--windowed 下 stdout=None 也会让 print 崩溃；已改为 ASCII（R2/->）并对 None stdout 重定向 devnull。

## 用户纠正：删除 env 文件，改为纯 exe 分发
- 用户明确：不要 requirements.txt / environment.yml（那意味着对方要 pip/conda 装环境 = 还要下载），
  要的是「Python 环境直接打进 exe」，对方双击即用、零安装。
- PyInstaller 冻结包本来就已内嵌解释器 + numpy + 标准库，所以 exe 本身就是自包含成品。
- 已删除 requirements.txt / environment.yml；README 第三节改为「方式 A=exe 零配置（推荐分发）」前置，
  「方式 B=源码运行（仅开发者）」，并移除项目结构中的 env 文件两行。
- 自包含验证：把 exe 拷到干净临时目录（无源码树、无 Python），`--nogui --noopen` 跑通，
  进程全部退出且生成 copper_dashboard.html（1.16MB）。dist/CopperPriceForecast.zip 经 tar -tf 确认仅含 CopperPriceForecast.exe。
- 交付物=dist/CopperPriceForecast.exe（25.1MB）+ dist/CopperPriceForecast.zip（24.8MB），二选一发对方即可。
