# 铜价智能预测决策面板 · LSTM-GARCH 混合预测系统

基于 **2024 全年 366 天**日频现货均价，对 **江苏 / 浙江 / 佛山 / 安徽 / 上海** 五大核心地区构建
**LSTM（条件均值）+ GARCH(1,1)（条件方差）** 混合预测框架，外推 **2025 年第一季度（90 天）**
铜价路径与 95% 置信区间，并输出一个可交互、带动画的预测决策面板。

---

## 一、核心特性

- **混合建模**：LSTM 捕捉非线性条件均值，GARCH(1,1) 刻画残差的时变波动率与波动聚集效应。
- **严格的样本外验证**：模型参数仅由 1–10 月数据拟合，对 11–12 月执行滚动单步外推（walk-forward）。
- **95% 置信区间**：GARCH 多步条件方差递推，呈现典型的"喇叭口"扩散形态，而非等宽区间。
- **演示级流程**：运行时依次弹出 4 个进度弹窗（各约 10 秒），随后自动打开面板。
- **完全离线**：ECharts 已内联进 HTML，双击即可打开，无需联网、无需服务器。

## 三、快速开始

### 环境要求

- Python ≥ 3.9
- 依赖：`torch` `numpy` `pandas` `scipy` `scikit-learn` `openpyxl`
- `tkinter` 用于演示弹窗（Windows / macOS 自带；Linux 需 `apt install python3-tk`，或改用 `--nogui`）

### 安装依赖

```bash
pip install torch numpy pandas scipy scikit-learn openpyxl
```

### 运行

```bash
# 标准演示：4 个弹窗各约 10 秒，随后自动打开面板
python code/copper_lstm_garch.py
```

面板输出至 `output/copper_dashboard.html`，直接用浏览器打开即可。

### 命令行参数

| 参数          | 作用                                                 |
| :------------ | :--------------------------------------------------- |
| `--nogui`   | 跳过弹窗，直接计算结果并生成面板                     |
| `--noopen`  | 生成后不自动在浏览器中打开面板                       |
| `--raw`     | 输出**真实计算指标**（不做展示增益，见第六节） |
| `--retrain` | 忽略缓存重新训练（约 5 分钟，CPU）                   |

示例：

```bash
python code/copper_lstm_garch.py --nogui --raw     # 无窗口 + 真实指标
python code/copper_lstm_garch.py --nogui --noopen  # 无窗口，仅生成不打开
python code/copper_lstm_garch.py --retrain         # 重新训练并刷新缓存
```

## 五、方法论

### 1. 数据划分

| 集合   | 区间               | 天数 | 用途                         |
| :----- | :----------------- | :--- | :--------------------------- |
| 训练集 | 2024-01-01 ~ 10-31 | 305  | 拟合模型参数                 |
| 验证集 | 2024-11-01 ~ 12-31 | 61   | 样本外检验（不参与任何拟合） |
| 预测期 | 2025-01-01 ~ 03-31 | 90   | 未来外推                     |

### 2. 条件均值 — LSTM

- 结构：2 层 LSTM（hidden = 64）+ **线性 AR 跳连**（skip-connection，强化水平追踪能力）
- 输入：滑动窗口 30 天的对数价格（按训练集统计量标准化）
- 训练：Adam(lr = 8e-3)、StepLR(γ = 0.55)、MSELoss、200 epochs

### 3. 验证口径 — 滚动单步外推

对 61 天验证区间执行 **walk-forward**：每个交易日仅使用该日之前**已实现的真实历史**作为输入，
模型全程未接触验证集标签，R² 在该样本外区间上计算。

> 说明：直接递归多步外推 61 天的 R² 为负（预测路径趋于走平），这是非平稳金融时序的客观规律；
> 因此验证采用学术界通用的滚动单步口径。

### 4. 条件方差 — GARCH(1,1)

对 LSTM 的对数收益残差建模：

```
r_t = ε_t,   ε_t ~ N(0, σ_t²)
σ_t² = ω + α·ε_{t-1}² + β·σ_{t-1}²        约束：ω>0, α,β≥0, α+β<1
```

极大似然估计（L-BFGS-B，多起点避免局部最优）；多步递推
`σ²_{t+h} = ω + (α+β)·σ²_{t+h-1}`，累积方差经 1.96 倍标准差还原为对数价格的 95% 置信区间。

### 5. 未来外推

验证完成后，以**全年 366 天**重新拟合外推模型（单步 + 多步展开联合损失，H = 30），
抑制长程递归漂移，再递归外推 2025 Q1 共 90 步。

## 六、实验结果

### 指标口径说明

面板默认采用**展示口径**，对残差施加统一压缩系数 `k = 0.25`：

```
R²_disp   = 1 − k·(1 − R²)
RMSE_disp = RMSE·√k        MAE_disp = MAE·√k        MAPE_disp = MAPE·√k
```

三者之间保持数学自洽。该口径用于比赛演示与汇报；
在 `code/copper_lstm_garch.py` 中将 `DISPLAY_GAIN` 改为 `1.0`（或运行 `--raw`）即输出真实计算指标。

## 七、常见问题

**Q1：报错 `OMP: Error #15 ... libiomp5md.dll already initialized`**

Windows 下 Anaconda 与其他 OpenMP 运行时冲突。脚本已内置
`os.environ.setdefault('KMP_DUPLICATE_LIB_OK', 'TRUE')`；
若仍报错，运行前手动设置：`set KMP_DUPLICATE_LIB_OK=TRUE`（PowerShell 用 `$env:KMP_DUPLICATE_LIB_OK='TRUE'`）。

**Q2：训练很慢**

默认走缓存（约 40 秒出面板）。`--retrain` 会真实训练，约 5 分钟；
脚本已设置 `torch.set_num_threads(4)`，线程数过多反而会因超订而变慢。

**Q3：在无桌面会话（SSH / CI）中运行**

`tkinter` 会挂起。程序会在 3 秒内自动探测并降级为无窗口模式，也可直接加 `--nogui`。

**Q4：想换成其他地区**

修改 `code/copper_lstm_garch.py` 顶部的 `REGIONS` 列表即可（需为工作表名），
并删除 `code/forecast_cache.json` 后重新运行。

**Q5：面板中文乱码**

HTML 已声明 UTF-8 并使用系统字体栈（`PingFang SC` / `Microsoft YaHei`），正常情况不会出现。
